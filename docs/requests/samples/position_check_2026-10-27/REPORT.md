## 1. llm_debate 第 2 轮有很强的近因效应（更正第 45 轮）

第 2 轮每个 agent 先看到自己的第 1 轮回答（assistant 轮），再按 `sources` 顺序看到另外两人的回答，
最后一条紧挨着指令。900 个第 2 轮步骤的呈现顺序与 `sources` 全部一致。第 2 轮字母等于哪个输入的第 1 轮字母：

| 情形 | 保持自己 | 第一条他人 | 最后一条他人 |
|---|---|---|---|
| 自己 = 第一条，最后一条不同（n=134） | 0.43 | 0.43 | **0.56** |
| 自己 = 最后一条，第一条不同（n=118） | 0.79 | **0.20** | 0.79 |
| 两条他人一致、与自己不同（n=126） | 0.12 | 0.87 | 0.87 |
| 三者都不同（n=69） | 0.25 | 0.22 | **0.51** |

2 对 1 时，agent 仍有 56% 改成最后一条；第一条只拉走 20%。第 1 轮三个 agent 的请求相同、可交换，所以这是
呈现顺序的效应。agent 2 是 agent 0、1 的最后一条，agent 1 是 agent 2 的最后一条，agent 0 对谁都不是最后一条。
第 1 轮 2:1 分裂时，第 2 轮采纳少数字母的比例：少数是 agent 2 时 agent 0、1 分别 29/49、28/49；少数是
agent 0 时 agent 1、2 都只有 8/41。

**更正**：第 45 轮把 medxpertqa_text_2287 解释为"agent 0 决定性"的顺序效应。系统性的效应是最后一条他人意见，
2287 的 agent 0 少数答案被全体采纳属于少见情形（少数是 agent 0 时最终跟随少数 8/41）。

mdagents 没有明显的顺序效应：专家意见不一致的 213 条运行里，最终答案与各位置专家一致的比例 0.54–0.66，CI 重叠；
独持某字母的专家几乎从不被采纳（各位置 0–12%）。

## 2. 试点翻转主要取决于同伴支持度，位置是它的代理

同伴 = 同轮其他 agent（llm_debate）/ 其他专家（mdagents）里已经说出正确字母的人数：

| | 同伴说对 0 | 1 | ≥2 |
|---|---|---|---|
| llm_debate 第 1 轮（同伴 2 人） | 2/16 | 1/1 | 2/3 |
| llm_debate 第 2 轮 | 0/17 | 0/1 | 0/1 |
| mdagents 专家（同伴 4 人） | 1/24 | 0/4 | 6/12 |

"首/中/末个错误步"的选点规则把票差编码进了位置：mdagents 第一个错误专家若在位置 4，说明前面的专家答对了，
小组分歧大、容易翻转（位置 0：0/16；位置 1、4：5/8）。规则也从没选到 llm_debate 第 1 轮 agent 2，而按第 1 节
它应当影响最大。

平凡基线（去掉 aggregator，79 点，12 个翻转；留一题外 / 样本内 AUROC）：
- 轮次 × 位置：0.76 / 0.88
- 同伴支持度（0、1、≥2）：0.78 / 0.89
- 只按轮次或 |D(t)|：0.49 / 0.68

样本很小，但方向清楚：MHT 的 (a)(b) 都成立，而且同伴支持度是比字母对错更强的可见特征（看得到小组是否分裂，
不需要知道正确答案）。

## 3. 对扩大方案的含义
- 评测时报告两个平凡基线：轮次 × 位置、同伴支持度。
- 候选点按（轮次, 位置）均匀分层，记录同伴支持度；不再用"首/中/末个错误步"。
- MHT 的对照候选点可行：字母正确的步骤，答错运行里 llm_debate 第 1 轮每个位置 23–36 个、mdagents 每个位置
  17–31 个；答对运行里每层 100 个以上。
- 近因效应本身是一个可报告的发现（框架 × 模型的性质），不混进标签。
